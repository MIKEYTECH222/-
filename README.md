# منصة خدمة مدارس الأحد (Sunday School Platform)

تطبيق ويب متكامل مصمم خصيصاً لخدمة مدارس الأحد بالكنيسة لإدارة المخدومين والخدام بشكل منظم ومربوط بقاعدة بيانات Supabase.

## المميزات الرئيسية:
- **نظام الحسابات والصلاحيات**: تسجيل حسابات منفصلة للخادم والمخدوم.
- **أرشيف الدروس والتلخيصات**: يتيح للخادم إضافة الدروس وتاريخها ليتمكن المخدوم من متابعة ما فاته.
- **نظام النقاط والعملات**: متابعة رصيد العملات والتحكم بها.
- **واجهة عصرية**: مبنية بـ Tailwind CSS وتدعم اللغة العربية بالكامل.
